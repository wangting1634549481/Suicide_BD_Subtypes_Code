# Suicide_BD_Subtypes_Code

This repository contains the analysis code associated with the manuscript:

**Gene-brain-behavior links revealing generative neurophysiological subtypes of suicide-related dysconnectivity in bipolar depression**

Repository:  
https://github.com/wangting1634549481/Suicide_BD_Subtypes_Code

## Overview

The code provided here supports the main analyses reported in the manuscript, including neurophysiological subtype identification, functional dysconnectivity characterization, clinical association analyses, transcriptomic analyses,validation of subtype distinctiveness via standardized classification， and spatial permutation analyses.

The current repository includes:

- `SmileGAN/` — code used for Smile-GAN-based neurophysiological subtype modeling.
- `spintest/` — code used for spatial permutation (spin-test) analyses.
- `standardized classification/` — code used for validation of subtype distinctiveness via standardized classification.
- `Clinical_Relevance_By_CCA.m` — canonical correlation analysis linking subtype expression to multidimensional clinical profiles.
- `Transcriptomic_Analyses.m` — transcriptomic analyses linking subtype-specific brain alterations to regional gene-expression patterns.
- `regionaltmap.m` — generation and processing of regional statistical maps.
- `subtype_Functional_Dysconnectivity.m` — characterization of subtype-specific functional dysconnectivity patterns.

Additional analysis code required for reproducing the reported results may be added or updated in this repository as part of the final reproducibility package.


## Software and Dependencies

The analyses were conducted using MATLAB and Python-based tools as described in the Methods and Supplementary Methods of the manuscript. Users should refer to the corresponding code files and manuscript for analysis-specific software requirements and parameter settings.

## Reproducibility

The repository is intended to facilitate replication of the main analytic workflow reported in the manuscript. Users applying the code to independent datasets should ensure that preprocessing, feature definitions, covariate adjustment, and model-input formats are consistent with those described in the manuscript.
